**Balanced Hidden-Spin Feedback for Prime-Sequence Fidelity Through One Billion**

Sean Brady — originator and conceptual director.
OpenAI ChatGPT and Codex — AI research collaborators.

The PDF/Word/Markdown/LaTeX copies, figures and data tables are the September27,
2026 manuscript draft. This repository publication is not a journal submission.
Scientific figures and all manuscript seed/error tables are included. The public
software and numerical reproduction commands are in the root README and
`docs/reproduction.md`; they replace the private-workstation launch instructions
used during the original experiment.

To rebuild the supplied PDF source with Tectonic0.17.0, from this directory:

```bash
tectonic Balanced_Hidden_Spin_Prime_Feedback.tex
```

Tectonic may download its TeX resources on first use. The supplied source already
contains references and the figure paths. Markdown is the editable narrative;
Word retains editable equations. Regenerating a document need not reproduce its
binary hash because PDF/document metadata and TeX resources may differ.
